## Task 1: Simple Application Communication Using Netcat

The objective of this task was to establish communication between two Linux hosts using the Netcat application. Netcat enables application-layer communication using TCP or UDP protocols and is commonly used to test network connectivity and services.

Network Topology

The same network topology created during Week 2 was reused.

Network details:

Four Linux Hosts
One Ethernet Switch
IPv4 Network
10.1.1.0/24
![Settings_IP](./Settings_IP.png)

Commonds:<br>
ip addr add 10.1.0.1/24 dev eth0 <br>
ip a <br>

[Setting IP Addresses Project](./Setting-IP-12323445.gns3project)



Netcat Server Configuration

Host1 was configured as the Netcat server.

Command used
nc -l -p 12345

Host2 acted as the Netcat client.

Command used
nc 10.1.1.1 12345
![NetCat Host 1](./netcat_Host1.png)

Communication

After the connection was established:

Client sent

Meghana Yellaboina

Server replied

My student id is 12323445

The successful exchange confirmed that TCP communication between the two hosts was functioning correctly.

## Task 2: Packet Capture

The purpose of this task was to capture packets travelling between hosts, save them as a packet capture (.pcap) file, transfer the file from the GNS3 server to the host computer, and verify the captured packets using Wireshark.
Starting Packet Capture

Packet capture was started on the Ethernet link connecting Host1 to the switch.

The capture type selected was:

Ethernet

Generating Network Traffic

While packet capture was active, network traffic was generated by performing:
ping -c 3 10.1.1.2
Three ICMP Echo Requests were transmitted from Host1 to Host2.
The captured packets confirmed that both the ping and Netcat communications were successfully recorded.
![Packet_Capture](./Packet_Capture.png)
[Captured Packets](./Capture-Basics-12323445-ping-netcat.pcap)



![FileZilla](./FileZilla.png)

Analysing the Capture
